# Find the Leader entry contract

- The large Play Hub card opens the fixed official daily board at `/play/find-leader`.
- The All Games card opens replayable mode at `/play/find-leader?mode=replayable`.
- Casual `PLAY AGAIN` generates a new category and ten-fighter lineup.
- Daily `REPLAY TODAY` repeats the same official board.
- Curated `REPLAY CHALLENGE` repeats the exact shared board.
- Only the official daily result affects streak and official-score history.
