# Native sharing scope

Octagon HQ now uses one native-share owner for:

- fighter profiles;
- fighter comparisons;
- Picks recaps.

The owner opens the platform share sheet with an exact canonical link. When native sharing is unavailable or fails, it copies that exact link instead. Cancelling the platform share sheet does not trigger an unwanted copy.

This rollout reuses the existing fighter-profile and Picks recap Share buttons and adds one Share Matchup action to the existing Compare screen.

The one remaining sharing PR is limited to Play challenge invitations and completed game results.
